# Little Things, Big Love — Birthday Scrapbook

A responsive birthday surprise website with your supplied couple photos, burgundy/rose/cream styling, animated falling hearts and sparkles, and interactive memory cards.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `birthday_scrapbook_fixed` folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html` to open it in a browser.

## Replace a memory photo
In the Memories section, use the **Change photo** link below a photo and select a picture from your computer. The replacement is saved in that browser where storage allows. It does not overwrite the original image files or automatically update a deployed copy.

## Flip a memory
Click or tap any photo card. Tap again to return to the photo. Keyboard users can focus a card and press Enter or Space.

## Important
Keep the `images` folder beside `index.html`, `style.css`, and `script.js`. Do not remove it or rename the supplied image files unless you also update their paths in `index.html`.
